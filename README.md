# PLP Python Week 4 Assignment

## File Descriptions
* `welcome.py`: Defines a function that generates personalized welcome messages for users.
* `toolbox.py`: Contains a set of utility functions to double numbers, check passing scores, and construct custom greetings with default parameters.

## Reflection
The `greet` function in `toolbox.py` was the most challenging to write because it required setting a default parameter value while still allowing custom greetings to be passed. Formatting the dynamic string correctly with standard punctuation also took careful attention.
